# AutoQuant-Lite 📈
### 轻量级 A 股量化回测工具 · 极简开箱即用

---

## 📖 项目简介
AutoQuant-Lite 专为**量化入门 & Python 数据分析**学习者打造，
零复杂配置、一站式完成：**股票数据爬取 → 均线指标计算 → 双均线策略 → 回测分析 → 可视化绘图**。

---

## 🎯 核心功能
- 📊 自动爬取 A 股日K线行情，支持前复权数据
- 📈 内置 MA5 / MA10 / MA20 多周期移动均线计算
- 🔔 经典双均线**金叉买入、死叉卖出**策略逻辑
- 📉 完整回测：总收益、最大回撤、交易胜率统计
- 🎨 专业可视化：K线走势 + 买卖信号标记 + 净值对比曲线
- 📄 自动导出 CSV 交易明细，留存每笔交易记录
