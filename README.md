\# AutoQuant-Lite 轻量级A股量化回测工具

✨ 一键运行，自动爬取股票数据 + 策略回测 + 可视化分析 ✨



\## 项目介绍

AutoQuant-Lite 是一个面向新手的轻量级量化工具，无需复杂环境，一键完成股票数据获取、技术指标计算、双均线策略回测与结果可视化。



\## 核心功能

\- 📊 自动爬取 A 股日 K 线数据（开盘/收盘/最高/最低/成交量）

\- 📈 计算 MA5、MA10、MA20 均线与日收益率

\- 🔔 双均线策略：金叉买入、死叉卖出

\- 🧪 完整策略回测：总收益、最大回撤、胜率

\- 🎨 专业图表展示：K线、买卖点标记、净值曲线对比



\## 使用方法

1\. 打开 main.py

2\. 修改股票代码、起止日期

3\. 直接运行：python main.py
